# Com Contribuir a Sóc de Poble

Primer de tot, gràcies per l'interès en voler col·laborar amb **Sóc de Poble**! Tota l'ajuda de bona fe és benvinguda, ja siga arreglant bugs, millorant l'accessibilitat o escrivint documentació.

## La Filosofia del 'Trellat'
Aquest projecte es regeix pel **Trellat**: el sentit comú valencià. Volem codi net, funcional, resistent (offline-first) i pensat per a la gent de poble (des de joves fins a iaies).
- No uses tecnologies o dependències innecessàries.
- Maximitza l'eficiència per a dispositius de gamma baixa.
- Respecta el Sistema de Disseny (tipografia, colors i mides).

## Passos per a Contribuir
1. Fes un *Fork* del repositori.
2. Crea una branca nova (`git checkout -b feature/nom-de-la-millora`).
3. Fes els teus canvis. Assegura't de passar el linter i els tests (`npm run test`).
4. Fes el commit amb un missatge clar (`git commit -m 'feat: afig nova funció'`).
5. Puja els canvis i obri un **Pull Request**.

Qualsevol dubte, consulta amb l'autor principal. Gràcies per ajudar a fer un Sóc de Poble indestructible!
