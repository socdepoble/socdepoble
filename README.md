## 🌾 Què és Sóc de Poble?

**Sóc de Poble** no és una app normal. És una **federació de nodes comarcals** que retorna la sobirania digital als pobles.

| Característica | Descripció |
|---------------|-----------|
| 🏠 **Local-First** | Les dades viuen al teu dispositiu. El núvol és només un mirall. |
| 🔒 **Privacitat** | No venem dades. No hi ha algoritmes de manipulació. |
| 🌐 **Offline** | Funciona sense connexió. Sincronitza quan tornes a la xarxa. |
| 🤝 **Comunitat** | Construït entre veïns, per a veïns. Sense ànim de lucre. |
| ♿ **Accessible** | WCAG 2.1 AA. Tecnologia per a tothom, sense excepcions. |

## 📜 MANIFEST DEL MAS DIGITAL: EL FUTUR DE SÓC DE POBLE

*«Si el servidor cau, el poble continua parlant. Si el cable es talla, la terra continua recordant.»*

Hem creuat la frontera del Local-First per endinsar-nos en el territori del **Network-Last**. Després de consolidar el transport en segon pla mitjançant un dimoni natiu d'extrema eficiència energètica (DTN), la infraestructura de "Sóc de Poble" es prepara per a la seua pròxima metamorfosi evolutiva. Aquesta és la fulla de ruta arquitectònica i filosòfica per a la dècada vinent.

### 🌲 I. L'EXPANSIÓ ESTÀTICA: EL BOSC DE SILICI (NODES ARBRE)
Fins ara, la xarxa Rhizome depenia exclusivament de les "mules de dades": humans caminant o conduint tractors amb els seus mòbils a la butxaca per creuar fragments d'informació d'una punta a l'altra de la vall. El següent pas és sembrar la infraestructura física.

Desplegarem **Nodes Arbre (Tree Nodes)**: microcontroladors d'ultra-baix cost (ESP32-C3 / nRF52 amb suport BLE i LoRa) encapsulats en resina biodegradable i resistent als raigs UV (PETG/ASA) impresa en 3D. Estaran alimentats per minúsculs panells solars i bateries 18650 recuperades, lligats a garroferes centenàries, senyals de trànsit en cruïlles de camins o a la teulada de les cooperatives.

*   **La Funció:** Actuaran com a *Buffers* de retenció perpètua (Blind Relays). Un ESP32 no renderitza UI; executa codi C/Rust nu. La seua única missió és despertar-se amb el sol, escoltar el nostre UUID sobirà, emmagatzemar els *blobs* binaris opacs a la seua memòria flash SPIFFS, i escopir-los al pròxim mòbil que passe prop.
*   **L'Impacte:** Crearem un "catxé físic" en el món real. Un senderista deixa un avís d'esllavissament en un camí forestal sense cobertura; el Node Arbre ho absorbeix. Dues hores després, un ciclista passa a 50 metres, el seu mòbil se sincronitza de manera transparent en *background*, i l'avís arriba a la plaça del poble. Hem convertit la pròpia orografia i la naturalesa en un enrutador gegant.

### 🧠 II. COGNICIÓ DISTRIBUÏDA: L'EIXAM DE LA "IAIA"
La Intel·ligència Artificial actual és un model de latifundi digital: enviem les nostres dades íntimes als servidors de *Big Tech* perquè una caixa negra que consumeix gigawatts ens retorne una resposta computada a milers de quilòmetres. Sóc de Poble destruirà aquest paradigma implementant **Cognició Distribuïda en l'Edge**.

Les futures versions de la "IAIA MarIA" i els seus agents no viuran al núvol, sinó a la NPU (Neural Processing Unit) dels telèfons dels agricultors. Utilitzarem LLMs ultra-quantificats (models d'1B a 3B paràmetres en 4-bit, via WebGPU o Llama.cpp natiu en Capacitor) que caben perfectament en 1GB de RAM.

*   **Intel·ligència d'Eixam (Swarm Intelligence):** Quan el mòbil d'un veí detecte (via càmera offline) un brot de *Xylella fastidiosa* en un ametler, el seu LLM local generarà un diagnòstic d'emergència. Aquest diagnòstic s'empaquetarà en un delta CRDT i viatjarà per la malla BLE.
*   **Acció Descentralitzada:** En arribar al telèfon del Capatàs o de l'Agrònom del poble, les seues pròpies IA locals (despertades pel dimoni natiu) analitzaran el *payload*, el creuaran amb el vent i la humitat dels seus propis sensors, i emetran alertes hàptiques urgents, sense que un sol byte haja tocat els servidors de Google o Amazon. La IAIA deixarà de ser un xatbot aïllat per a convertir-se en el **sistema nerviós compartit del territori**.

### 🏛️ III. EL LLEGAT "ZERO NETWORK & ZERO PATCH": LA PEDRA SECA DIGITAL
Vivim en l'era del tecno-feudalisme. Les corporacions dissenyen programari que ens converteix en ostatges: si no pagues la subscripció mensual del núvol, si el cable transoceànic es talla, o si decideixen apagar la seua API perquè el teu poble "no és rendible", la teua comunitat desapareix digitalment. Les seues aplicacions són terminals tontos que assumeixen 5G infinit.

La doctrina **"Zero Network & Zero Patch"** és la nostra declaració d'independència. Hem dissenyat "Sóc de Poble" amb la mateixa filosofia que els murs de **Pedra Seca** dels nostres bancals:
*   **Sense morter (Sense servidors centrals):** Els murs se sostenen pel pes, la fricció i l'equilibri matemàtic de les pròpies roques (els mòbils dels veïns comunicant-se via P2P). Si en lleves una, l'estructura es reajusta (CRDT).
*   **Materials locals (Local-First):** La xarxa es reconstrueix amb l'energia i els dispositius que ja estan en el territori.
*   **Fet per durar segles (Zero-Patch):** Si demà l'equip de desenvolupament desapareix, l'aplicació continuarà funcionant intacta d'ací a 10 anys, permetent que un poble continue comerciant, organitzant les seues festes i preservant la seua memòria.

**Què li estem retornant realment al món rural?** 
No els estem donant una "app bonica". Els estem retornant la seua **Dignitat, la seua Propietat i la seua Sobirania**. Els donem l'equivalent digital de posseir la seua pròpia terra i les seues pròpies llavors. Un arxiu (el *solatge*) que sobreviu en els discos durs locals de cent veïns, replicat i immutable, a prova de censura.

Si demà les antenes de telecomunicacions col·lapsen després d'una DANA, un incendi devastador o una fallada crítica nacional, **Sóc de Poble continuarà funcionant**. Els veïns continuaran comerciant, els bàndols de l'ajuntament continuaran propagant-se de butxaca a butxaca, i la memòria dels vells continuarà bategant.

La tecnologia moderna ens va prometre el món a canvi de la nostra sobirania. Nosaltres hem utilitzat la seua mateixa tecnologia per recuperar la nostra terra.

## 🚀 Inici Ràpid

### Prerequisits

```bash
- Node.js >= 20.x
- npm >= 10.x
- Git
```

### Instal·lació

```bash
# 1. Clonar el repositori
git clone https://github.com/socdepoble/socdepoble.git
cd socdepoble

# 2. Instal·lar dependències
npm ci

# 3. Configurar variables d'entorn
cp .env.example .env
# Editar .env amb les teues claus de Supabase

# 4. Iniciar en mode desenvolupament
npm run dev
```

### Build per a Producció

```bash
# Build optimitzat
npm run build

# Vista prèvia del build
npm run preview

# Executar tests
npm run test

# Tests amb cobertura
npm run test:coverage
```
