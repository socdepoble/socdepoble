# Política de Seguretat de Sóc de Poble

## Versions Suportades

L'única versió amb suport de seguretat actiu és l'última versió en la branca `main`.

| Versió | Suportada |
| ------ | ------------------ |
| `main` | :white_check_mark: |
| Antigues | :x: |

## Informar d'una Vulnerabilitat

Si trobes qualsevol vulnerabilitat de seguretat (filtració de claus, problemes d'accés, injeccions SQL o vulnerabilitats XSS/CSRF), si us plau **NO** crees un Issue públic.

Fes servir la pestanya "Security" > "Advisories" per reportar-ho de manera privada, o envia un avís privat a l'autor del repositori. Es respondrà amb el màxim "Trellat" possible i s'aplicarà un pedaç el més ràpidament possible.
