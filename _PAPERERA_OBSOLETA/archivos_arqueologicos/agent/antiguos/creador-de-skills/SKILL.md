# CREADOR DE SKILLS

## Cuándo usar este skill

- Cuando el usuario pida crear un skill nuevo.
- Cuando se necesite un estándar de formato para nuevas habilidades.
- Cuando haya que convertir un procedimiento en una herramienta reutilizable.

## Inputs necesarios

- Nombre del skill.
- Objetivo o problema que soluciona.
- Flujo de trabajo o pasos básicos (opcional).

## Workflow

1. **Planificación**: Definir la estructura de carpetas y recursos necesarios.
2. **Validación**: Asegurar que cumple con las reglas de YAML y estilo Antigravity.
3. **Escritura**: Generar el contenido de SKILL.md y archivos asociados.
4. **Revisión**: Checklist final de coherencia.

## Instrucciones

- Mantener la ruta en `agent/skills/<nombre-del-skill>/`.
- Usar YAML frontmatter correcto.
- Definir triggers claros con ejemplos.
- Aplicar niveles de libertad según el riesgo.

## Output (formato exacto)

Carpeta: `agent/skills/<nombre-del-skill>/`
SKILL.md completo con frontmatter.
Recursos adicionales si aplica.
