# SKILL: Ganglis Basals
Lògica estadística pura en JavaScript Vanilla que corre al client sense IAs pesades. Avalua el ritme tàctil, els FPS en el desplaçament i el temps de resposta (TRD). Té el poder d'alterar variables CSS root a l'instant per a facilitar-li la vida al llaurador (ex. eliminar animacions si cau el framerate o ampliar el botó a 64px).
