### 3) Estrangulamiento P2P Offline-First (CRDT Ghosting)
**Fisura Letal:** Sincronización asíncrona entre dispositivos rurales (3G intermitente) genera `ghost writes` en IndexedDB. Un dispositivo A escribe chunk modificado mientras B lo tiene cacheado. Reconciliación CRDT simple falla con conflictos circulares.

**Métrica de Colapso:** 3 dispositivos concurrentes → 27% datos inconsistentes tras 24h offline → pérdida confianza sistema.

**Código Solución (Tombstone CRDT):**
```js

  constructor() {
    this.vectorClock = new Map();
    this.tombstones = new Set(); // Chunks revocados
  }
  
  async mergeRemoteChunk(chunkId, remoteData, remoteClock) {
    const localData = await this.getLocalChunk(chunkId);
    if(!localData) return this.storeChunk(chunkId, remoteData);
    
    // Vector Clock comparison
    const localClock = localData.vectorClock;
    const happensBefore = this.clockHappensBefore(localClock, remoteClock);
    
    if(happensBefore === 'local') return;
    if(happensBefore === 'remote') {
      this.tombstones.add(chunkId);
      return this.storeChunk(chunkId, remoteData);
    }
    
    // Concurrent: merge strategy por tipo contenido
    const merged = this.contentMergeStrategy(localData.data, remoteData.data);
    this.storeChunk(chunkId, merged, this.advanceClock(localClock, remoteClock));

}
```
