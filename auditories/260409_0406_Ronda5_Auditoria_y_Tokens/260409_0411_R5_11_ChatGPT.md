# ⚠️ 1. AUDITORÍA EXTREMA (Fase 2)

## 🧨 VECTOR 1 — INDEXEDDB: EVICTION SILENCIOSO (SAFARI = ENTORNO HOSTIL)

---

## 💀 PROBLEMA REAL

Safari iOS 14:

* No garantiza persistencia
* Eviction ocurre:

  * por presión de almacenamiento global
  * por inactividad
  * por política interna opaca (Jetsam indirecto)

👉 Resultado:

* pérdida parcial de datos
* inconsistencias entre Cache API e IDB
* corrupción lógica silenciosa

---

## 🧠 PATRÓN DE COLAPSO

1. Guardas:

   * 200 imágenes (IndexedDB)
   * 100 HTML (Cache)

2. iOS necesita memoria/storage

3. El sistema:

   * elimina blobs de IDB (sin evento)
   * mantiene referencias en app

👉 Resultado:

```js
img.src = blobURL // pero blob ya no existe
```

→ UI rota sin error claro

---

## 🛡️ SOLUCIÓN: VERIFICACIÓN CRIPTOGRÁFICA + REHIDRATACIÓN

---

### 📦 METADATA STORE

```js id="idbmeta1"
db.put('meta', {
  key: 'img-001',
  hash: 'abc123',
  size: 120394,
  lastAccess: Date.now()
});
```

---

### 🔍 VALIDACIÓN EN LECTURA

```js id="idbcheck1"
async function getImage(key) {
  const blob = await db.get('images', key);
  const meta = await db.get('meta', key);

  if (!blob) return null;

  const hash = await hashBlob(blob);

  if (hash !== meta.hash) {
    await db.delete('images', key);
    return null;
  }

  return blob;
}
```

---

### 🔁 REHIDRATACIÓN

```js id="rehyd1"
async function ensureImage(key, url) {
  let blob = await getImage(key);

  if (!blob) {
    const res = await fetch(url);
    blob = await res.blob();

    await db.put('images', blob, key);
  }

  return URL.createObjectURL(blob);
}
```

---

## ⚠️ MÉTRICA

* ratio fallos IDB > 5% → activar modo degradado

# 🧨 VECTOR 2 — CACHE API: CORRUPCIÓN LÓGICA

---

## 💀 PROBLEMA

Cache API:

* no versiona automáticamente
* no invalida coherentemente
* puede mezclar versiones

---

## 🧠 ESCENARIO

* actualizas HTML chunks
* cache antigua persiste
* offsets ≠ contenido real

👉 Virtual scroll colapsa

---

## 🛡️ SOLUCIÓN: VERSIONADO FUERTE

---

```js id="cachev1"
const CACHE_VERSION = 'v3';

async function getCache() {
  return await caches.open(`book-${CACHE_VERSION}`);
}
```

---

### 🔥 INVALIDACIÓN TOTAL

```js id="cachev2"
async function clearOldCaches() {
  const keys = await caches.keys();

  for (const key of keys) {
    if (!key.includes(CACHE_VERSION)) {
      await caches.delete(key);
    }
  }
}
```

---

## ⚠️ REGLA

👉 Nunca mezclar versiones
👉 Nunca confiar en cache existente

# 🧨 VECTOR 5 — MEMORY FRAGMENTATION (OCULTO)

---

## 💀 PROBLEMA

* createObjectURL sin revoke
* blobs acumulados
* GC no libera rápido

---

## 🛡️ SOLUCIÓN

```js id="blob1"
let activeURLs = new Set();

function trackURL(url) {
  activeURLs.add(url);
}

function cleanupURLs() {
  activeURLs.forEach(url => URL.revokeObjectURL(url));
  activeURLs.clear();
}
```

---

## ⚠️ EJECUTAR

* al cambiar nodo
* al hacer pruning

---

## 🛡️ SOLUCIÓN

👉 recalibración periódica

```js id="recal1"
function recalibrate() {
  let acc = 0;

  for (let i = 0; i < items.length; i++) {
    offsets[i] = acc;
    acc += items[i].height;
  }
}
```
