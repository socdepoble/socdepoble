# EL MANUAL DEL SOBRINO
### *Lo que tienes en las manos y cómo no perderlo*

---

Hola.

Si estás leyendo esto, probablemente encontraste un iPad viejo, un USB, o quizás este papel impreso dentro de una caja. Quizás la persona que te lo dejó ya no está. Quizás no sabes nada de programación. No importa. Este documento está escrito exactamente para ti.

---

**¿Qué es esto?**

Lo que tienes es una biblioteca. No una biblioteca en internet — una biblioteca que vive *dentro del propio dispositivo*, como un libro que no necesita librería para existir.

Se llama **Sóc de Poble**. Contiene la memoria de un pueblo: historias, voces, fotografías, conocimientos y costumbres que alguien consideró demasiado importantes para dejar que desaparecieran. La persona que lo construyó sabía que los servidores de internet cierran, que las empresas desaparecen, que los enlaces se rompen. Por eso lo guardó aquí, en local, en este cacharro que tienes en las manos.

---

**¿Cómo lo abro?**

*Si tienes el iPad:*
Enciéndelo. Busca en la pantalla de inicio un icono que ponga "Sóc de Poble" o similar. Pulsa. Si no está, abre Safari y escribe `socdepoble.org` — pero eso requiere internet. Si no hay internet, sigue leyendo.

*Si tienes el USB:*
Conéctalo a un ordenador. Dentro encontrarás una carpeta. Abre el archivo `index.html` con cualquier navegador moderno (Chrome, Firefox, Edge). Se abrirá la biblioteca entera sin necesidad de internet.

*Si solo tienes este papel:*
El papel es el último recurso. Busca a alguien joven que sepa usar una inteligencia artificial (en 2040 las hay en todos lados). Muéstrale las páginas con el código. Dile: *"Esto es una aplicación web. ¿Puedes reconstruirla para mí?"* El código está diseñado para ser legible por máquinas. Una IA moderna debería poder hacerlo.

---

**¿Por qué no necesita internet?**

Porque todo el contenido está guardado en la memoria interna del dispositivo, en una base de datos invisible llamada IndexedDB. Funciona como un disco duro dentro del navegador. Mientras el iPad encienda y Safari funcione, la biblioteca existe.

Si el dispositivo lleva mucho tiempo sin usarse, puede que Safari haya borrado algunos datos para liberar espacio. En ese caso, la primera vez que lo abras necesitarás conexión a internet unos minutos para que se vuelva a descargar. Después, vuelve a funcionar sin red.

---

**¿Y si el iPad ya no enciende?**

Primero: intenta cargarlo. Estos dispositivos pueden estar meses sin batería y recuperarse.

Si definitivamente no enciende, el contenido no está perdido. Está en el USB de respaldo (si lo hay). Está en `socdepoble.org` si el dominio sigue activo. Y si nada de eso funciona, está en este papel — y en la cabeza de las personas que lo vivieron.

La tecnología es el último recurso. La memoria humana es el primero.

---

**¿Puedo añadir cosas? ¿Puedo modificarlo?**

Sí, pero necesitarás ayuda técnica para hacerlo bien. El sistema fue diseñado para durar, no para ser modificado a la ligera. Si quieres añadir contenido nuevo, busca a alguien que entienda HTML básico, o usa una IA y dile: *"Tengo una aplicación web en HTML puro llamada Sóc de Poble. Quiero añadir un artículo nuevo. Aquí está la estructura del código existente..."*

Lo más importante: **no borres nada sin hacer una copia antes.** Copia toda la carpeta en otro USB antes de tocar nada.

---

**¿Qué hago si algo falla?**

Respira. Nada de lo que hagas rompiendo el archivo del iPad afecta al original en el servidor o en el USB. Siempre puedes volver a empezar desde la copia.

Si la web no carga, cierra Safari completamente (desliza hacia arriba en el gestor de apps) y vuelve a abrirla.

Si los textos o imágenes no aparecen, necesitas conexión a internet una vez para que se descarguen de nuevo.

Si absolutamente todo falla y no sabes qué hacer: **guarda el USB en un lugar seguro y busca ayuda.** El contenido sobrevivirá mientras exista una copia física o digital en algún lugar.

---

**Una última cosa**

Quien construyó esto no lo hizo para que durara un año. Lo hizo para que durara décadas. Para que tú, en 2040 o en 2050, pudieras abrir este iPad o este papel y encontrar algo real: la voz de alguien que ya no está, el nombre de una calle que ya no existe, la receta de algo que nadie hace ya.

Si esto ha llegado hasta tus manos, la primera parte funcionó.

El resto depende de ti.
