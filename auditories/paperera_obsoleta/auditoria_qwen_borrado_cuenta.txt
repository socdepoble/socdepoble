CONTEXTO Y CÓDIGO A JUZGAR:

1. SQL / Base de Datos (Ya se habilitó la cascada previamente)
Nueva función RPC que llama el usuario para borrarse limpiamente.
```sql
CREATE OR REPLACE FUNCTION delete_user()
RETURNS void LANGUAGE plpgsql SECURITY DEFINER AS $$
BEGIN
    DELETE FROM auth.users WHERE id = auth.uid();
END;
$$;
```

2. Lógica Frontend (supabaseService.js)
```javascript
    async deleteCurrentUser() {
        try {
            const { error: rpcError } = await supabase.rpc('delete_user');
            if (rpcError) throw rpcError;
            
            await supabase.auth.signOut();
            return { success: true };
        } catch (e) {
            throw e;
        }
    }
```

3. Interfaz de Usuario (ProfileSettingsModal.jsx, fragmento inyectado en la pantalla de Configuración):

- Un botón rojo primario "Eliminar el meu compte".
- Al pulsar, modal interno "Doble Confirmació (NO es pot desfer)" con dos botones SÍ/CANCELAR.
- Si da error, alerta al usuario. Si no, cierra modal y redirige al Landing (`navigate('/')`).
