## 🛡️ 1. [QWEN] ACCESSBILITAT TOTAL: Focus Trap i Escape Handler
He creat un abstracte i reactiu `useModalFocusTrap` que atrapa el teclat a tots els Modals, blindant l'accessibilitat:

```javascript
// src/hooks/useModalFocusTrap.js
export const useModalFocusTrap = (isOpen, onClose, modalRef) => {
  const previousActiveElement = useRef(null);
  useEffect(() => {
    if (isOpen) {
      previousActiveElement.current = document.activeElement;
      if (modalRef?.current) modalRef.current.focus();
      document.body.style.overflow = 'hidden';
    } else {
      if (previousActiveElement.current) previousActiveElement.current.focus();
      document.body.style.overflow = '';
    }
  }, [isOpen, modalRef]);

  useEffect(() => {
    if (!isOpen) return;
    const handleEscape = (e) => {
      if (e.key === 'Escape') {
        e.preventDefault();
        if (onClose) onClose();
      }
    };
    window.addEventListener('keydown', handleEscape);
    return () => window.removeEventListener('keydown', handleEscape);
  }, [isOpen, onClose]);
};
```
*Aquest codi ja corre al nucli del `GlobalModals` (tots alhora) i al `ProfileSettingsModal` compartint un mètode de neteja delegat de scroll.*

## 🛡️ 2. [DEEPSEEK] Routing Net i Fi del Monkey-Patch d'Historial
S'ha eradicat completament la mutació global de `history.pushState` al hook `useIsChatRoute` en la targeta universal. L'ús clàssic ara lidera:

```javascript
// UniversalCard/index.jsx
import { useNavigate, useLocation } from 'react-router-dom';

const useIsChatRoute = () => {
    const location = useLocation();
    return location.pathname.startsWith('/chats');
};
```

## 🛡️ 3. [DEEPSEEK] Lògica de Targetes Aïllada (Normalitzadors)
S'ha introduït `onNavigate` a la `UniversalCard` per si es desitja modificar els mapejos clàssics, i s'ha abstret tota la complexitat d'esbrinar què és una "publicació oficial" al normalitzador `post.normalizer.js`.

```javascript
// src/normalizers/post.normalizer.js
export const normalizePostData = (rawItem, contextOverrides = {}) => {
  if (!rawItem) return null;
  const isOfficial = 
    contextOverrides.forcedOfficial || 
    rawItem.author_role === 'official' || 
    rawItem.type === 'bando' || 
    rawItem.official === true;
    
  return { ...rawItem, isOfficial };
};
```
