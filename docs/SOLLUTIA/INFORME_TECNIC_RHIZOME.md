# 🧶 INFORME TÈCNIC: Protocol Rhizome (Rizoma)

**Projecte: Sóc de Poble | v11.0.0-GOLDEN-DEAL**
**Per a: Sollutia S.L. & Equip de Desenvolupament**

## 1. Visió Tecnològica: La Microxarxa Federada

El Protocol Rhizome no és una xarxa social centralitzada (estil Facebook), sinó un ecosistema de **Microxarxes Comarcals Autònomes**. Cada comarca (per exemple, L'Alcoià, El Comtat, La Vall d'Albaida) opera el seu propi "Node IAIA".

### Característiques clau:

- **Sobirania de Dades**: Cada node s'administra de forma independent per entitats/ajuntaments locals.
- **Federació d'Intel·ligència**: Els agents IA (IAIA MarIA, etc.) tenen el context específic de la seva terra (llengua, tradicions, punts d'interès).
- **Comunicació Inter-Rhizome**: Ponts de dades segurs que permeten que un usuari de Alcoi pugui interactuar amb un de Gandia sense sortir de la seva identitat local.

## 2. Stack Tecnològic (L'Arquitectura Bàsica)

- **Frontend**: React + Tailwind CSS (Disseny GEM MODERN v2.0).
- **Backend/DB**: Supabase (PostgreSQL + Auth + Realtime) per a nodes individuals.
- **Motor d'IA**: Gemini Pro / Flash API, parametritzat amb els "Rituals d'Activació Sóc de Poble".
- **Asset Mirroring (Bridge Genesis)**: Sincronització intel·ligent d'actius visuals per garantir la identitat visual a tots els nodes.

## 3. Seguretat i Resiliència: Protocol BÍBLIA

- **Modo Arquitecte**: Sistema d'auto-documentació integrat que permet a qualsevol informàtic entendre i reconstruir la logica del sistema en minuts.
- **Arquitectura Off-the-Grid**: Capacitat de funcionar amb protocols locals en cas de fallada de la xarxa global.

## 4. Potencial d'Escabilitat

El sistema està dissenyat per ser replicat. Per a Sollutia, això significa:

- **Templates de Node**: Creació de nous nodes comarcals de forma automatitzada.
- **Manteniment Centralitzat / Dades Distribuïdes**: Gestió tècnica d'alt nivell des d'un centre de control (Sollutia) mentre la propietat de les dades queda en la comarca.
