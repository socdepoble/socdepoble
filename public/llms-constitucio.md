# ⚖️ Constitució: Les Lleis de GEM MODERN

Aquestes són les línies roges, els manaments inamovibles que regeixen el nostre codi i la nostra manera de treballar. No importa qui estiga picant codi (humà o IA), el **Trellat** sempre té l'última paraula.

## Les 10 Lleis Inamovibles

1. **HTML crea el significat:** La Persona és l'HTML. Sense estils in-line, purament semàntic. L'estructura de l'HTML (h1, h2, p, ul) dóna la informació, el CSS només vesteix.
2. **CSS crea la identitat:** L'Acte Reflex. L'estil viu als fulls d'estil globals (com `UniversalPage.css`), injectant bellesa de manera automàtica.
3. **Tailwind només organitza l'espai:** L'utilitzem estrictament per a Layout (`flex`, `grid`, `gap`, `w-full`, `justify-between`). Prohibit utilitzar-lo per a colors, radis o estètica en els components de negoci.
4. **Les variables governen el sistema:** Si no existeix com a `var(--sp-...)`, no s'utilitza. Aquesta és la base de la nostra parametrització absoluta.
5. **Els components són universals:** No reinventes la roda. Si necessites un botó, usa `<UniversalButton>`. Si necessites un targeta, usa `<UniversalCard>`. Aquests components hereten directament el Trellat.
6. **L'accessibilitat no és opcional:** Els botons mesuren 56px per a mans brutes (Mans Feineres). El contrast assoleix la certificació AAA en Mode Bancal. 
7. **El Mode Bancal preval:** Si alguna cosa és bonica però no es pot llegir sota el sol amb un iPad de 2016, no s'aprova. La funcionalitat venç a l'estètica fràgil.
8. **Menys JavaScript és millor JavaScript:** La Termodinàmica A10. No malgastes bateria amb animacions calculades via JS. El CSS és qui s'encarrega de les transicions (`transform`, `opacity`).
9. **Cada element ha de degradar elegantment:** Si no hi ha internet (Offline-first), si no hi ha dades, o si hi ha errors, el sistema no es penja. Expliquem l'estat amb calidesa a l'usuari.
10. **El Trellat té l'última paraula:** Si una d'aquestes regles, per motius matemàtics o d'enginyeria, fa que un uelo es frustre, **la regla es trenca immediatament**. L'empatia humana sempre guanya.

> "La tecnologia ha d'adaptar-se al poble. El poble no ha d'adaptar-se a la tecnologia."
