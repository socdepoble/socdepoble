#### **🔹 CAPA 3: PROTECCIÓ EN TEMPS D'EXECUCIÓ (Runtime)**
- **Middleware de React:**
  Afegir un **middleware** a l’aplicació que **comprovi** si el fitxer té un segell vàlid abans de renderitzar-lo.
  **Exemple:**
  ```jsx
  // src/middleware/lockChecker.js
  import fs from 'fs';
  import crypto from 'crypto';
  import path from 'path';

  export function checkLock(filePath) {
    const lockFile = path.join(path.dirname(filePath), `${path.basename(filePath)}.lock`);
    if (fs.existsSync(lockFile)) {
      const lock = fs.readFileSync(lockFile, 'utf8');
      const currentHash = crypto.createHash('sha256').update(fs.readFileSync(filePath)).digest('hex');
      const lockHash = lock.match(/hash:\s*["']?([^"'\s]+)/)?.[1];
      if (currentHash !== lockHash) {
        throw new Error(`❌ ${filePath} ha sigut modificat sense permís!`);
      }
    }
  }
  ```
  **Ús a l’aplicació:**
  ```jsx
  // A l'inici de l'aplicació (ex: App.jsx)
  import { checkLock } from './middleware/lockChecker';
  checkLock('./src/pages/features/DesignSystem.jsx');
  ```
