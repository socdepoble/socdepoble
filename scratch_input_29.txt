# 1. La Clau de Protecció (Permís Actiu)

Propose implantar una norma arquitectònica formal:

## Estat dels fitxers

### 🟢 VERD (Obert)

Es poden modificar lliurement.

```yaml
status: OPEN
```

---

### 🟡 GROC (Estabilitzat)

Només canvis puntuals.

```yaml
status: STABLE
```

Exemple:

* corregir un bug
* afegir una propietat
* millorar accessibilitat

Prohibit:

* reescriure el fitxer sencer

---

### 🔴 ROIG (Tancat)

```yaml
status: LOCKED
```

Exemple:

```jsx
/**
 * SOSP LOCK
 * status: LOCKED
 * owner: Consell de la Petorreta
 * version: 1.0
 */
```

Quan una IA detecta això:

### Regla obligatòria

NO POT:

* reestructurar
* renombrar
* substituir
* refactoritzar massivament

Només pot:

* llegir
* documentar
* proposar canvis

---
